# IfcRadialExcavation

A radial underground excavation where the tunnel profile is changed, e.g. widened.
<!-- end of short definition -->

## Attributes

### PredefinedType
A list of types to further identify the radial excavation. Some property sets may be specifically applicable to one of these types.

## Formal Propositions

### HasObjectType
The attribute ObjectType shall be given if the predefined type is set to USERDEFINED.
