# IfcFaceExcavation

A longitudinal underground excavation either of the full or parts of the face.
<!-- end of short definition -->

## Attributes

### PredefinedType
A list of types to further identify the face excavation. Some property sets may be specifically applicable to one of these types.

## Formal Propositions

### HasObjectType
The attribute ObjectType shall be given if the predefined type is set to USERDEFINED.
