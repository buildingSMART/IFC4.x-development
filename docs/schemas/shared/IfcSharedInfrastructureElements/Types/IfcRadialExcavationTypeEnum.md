# IfcRadialExcavationTypeEnum

This enumeration defines the different method predefined types for radial excavation that can specify an _IfcRadialExcavation_.
<!-- end of short definition -->

## Items

### PROFILEENLARGEMENT
Lateral enlargement of a tunnel profile.

### REPROFILING
Tunnel profile laterally reprofiled, as corrective measure to restore the planned profile, typically to compensate for radial deformation or inaccurate excavation.

### NICHE
Lateral recess in a tunnel wall.

### USERDEFINED
User-defined type.

### NOTDEFINED
Undefined type.
