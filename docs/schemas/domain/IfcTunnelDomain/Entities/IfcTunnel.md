# IfcTunnel

An artificial underground passage.

> NOTE&nbsp; Definition from PIARC: Long enclosed transport route
<!-- end of short definition -->

## Attributes

### PredefinedType
A list of types to further identify the tunnel. Some property sets may be specifically applicable to one of these types.

## Formal Propositions

### CorrectPredefinedType
Either _PredefinedType_ is unset or the inherited attribute _ObjectType_ shall be provided, if the _PredefinedType_ is set to USERDEFINED.
