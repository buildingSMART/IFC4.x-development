# IFC4.3.2.0

This is the official buildingSMART International repository for IFC 4.3-4.4. This branch, called `ifc4.3-main`, contains the IFC4.3.2.0 Specification.

> [!IMPORTANT]
> The formal 4.3.2.0 release, as approved by ISO, is published at: https://standards.buildingsmart.org/IFC/RELEASE/IFC4_3/ and https://www.iso.org/standard/84123.html
> 
> You are viewing the DEVELOPMENT version, which includes minor fixes to errors like spelling and additional clarifications **added post-ISO release**. 

The updated builds are automatically published here:
- GitHub Repository of all openBIM standards, both official releases and in development: https://github.com/buildingSMART/Standards-builds (previously: ~~https://github.com/buildingsmart/ifc4.3.x-output~~)
- The HTML version: https://standards.buildingsmart.org/IFC/DEV/IFC4_3/ (previously: ~~http://ifc43-docs.standards.buildingsmart.org/~~)
- The translation files: https://github.com/buildingSMART/IFC-translations
